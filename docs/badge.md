#### Components

# Badge

The smallest shape in the library: a count or a short status.

```html live
<span class="pui-badge pui-solid pui-error">3</span>
<span class="pui-badge pui-soft pui-success">active</span>
```

### Styles and colors

A badge takes the same styles and colors as everything else:

```html live
<span class="pui-badge pui-solid pui-theme">Solid</span>
<span class="pui-badge pui-soft pui-theme">Soft</span>
<span class="pui-badge pui-outline pui-theme">Outline</span>
```

### Rounded

```html live
<span class="pui-badge pui-solid pui-error pui-rounded-full">9</span>
```

### Inside other components

```html live
<button class="pui-btn pui-outline pui-surface">
  Inbox
  <span class="pui-badge pui-solid pui-theme pui-rounded-full">12</span>
</button>
```
