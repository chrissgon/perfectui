Perfect UI 1.0 is a rewrite. The whole library is 3.2 kB of CSS and 0.5 kB of JavaScript, gzip, with no runtime dependencies, no CSS reset, no font import, and no rule that is not attached to a `pui-` class. The browser does the work (`<dialog>`, `popover`, `<details>`), and JavaScript only fills in what a browser is missing.

Documentation: https://perfectui.dev

## Highlights

- **Three classes per element.** A shape, a style and a colour: `pui-btn pui-outline pui-theme`. Seven colour roles and four styles, composed instead of listed.
- **Native HTML, native behaviour.** The modal is a `<dialog>` opened with `commandfor`, the dropdown is a `popover`, the tooltip uses `interestfor`, the accordion is `<details name>`. Overlays are placed with CSS anchor positioning.
- **JavaScript only where a browser falls short.** One 493 B loader downloads a fallback only for the features the browser lacks. ESM only, safe to import on the server, nothing on `window`.
- **Dark mode with nothing to configure.** Colours are declared with `light-dark()`, follow the operating system, and one attribute (`data-pui-mode`) forces a mode.
- **Plays well with your CSS.** Every rule lives in `@layer pui.*`, so a Tailwind utility or your own class wins without `!important`.
- **Measured, not promised.** `perfectui.css` is 3,256 B and `js/index.js` 493 B (`gzip -9 -n`); the documentation site recomputes the numbers at every build.

## Upgrading from 0.x

1.0 changes class names (every class takes the `pui-` prefix), splits style from colour, and moves components onto native elements. The migration guide walks through it section by section: https://perfectui.dev/docs/v1/getting-started/migrating-from-0-x

0.x stays available: `npm i @chrissgon/perfectui@0`, and the source on the `v0` branch.

## Since 1.0.0-beta.1

- **forms:** unchecked radios and switches stay empty when `:indeterminate` matches.
- **modal:** the dialog stays centred under CSS resets that zero margins.
- **checkbox:** the mixed state shows on checkboxes inserted after load.
- **overlays:** dropdowns and tooltips are placed against the viewport, so a menu in a sticky header stays under its trigger while the page scrolls (Safari and iOS), and a menu at the bottom edge opens upward (Chromium).

## Install

```sh
npm i @chrissgon/perfectui
```

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@chrissgon/perfectui@1.0.0/dist/perfectui.css"
/>
<script type="module">
  import "https://cdn.jsdelivr.net/npm/@chrissgon/perfectui@1.0.0/dist/js/index.js";
</script>
```
