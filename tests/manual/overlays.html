Perfect UI v1 — overlay review

The parts that only exist once you click or hover them: overlay directions, tooltip styles, moving between modals, and the accordion icon hook. Everything here is native in Chromium. To exercise the fallbacks instead, serve this folder over http and import dist/js/index.js: a module cannot be loaded from a file:// page.

1 — dropdown directions

Click each one. The default opens below, aligned to the trigger's starting edge. pui-top, pui-start and pui-end move it. Each flips to the opposite side when the preferred one does not fit, which the last example shows on purpose.

4 — moving between modals

A button carries one command, so opening the next modal does not close the one you are in. Stacking is what you get for free: the second opens on top, and closing it reveals the first. Swapping needs the current dialog closed on the same click, which is the recipe in the docs.

5 — the rest of the modal

closedby="any" dismisses on a click outside; leaving it off gives a static backdrop. Long content scrolls inside the dialog.

6 — accordion icon hook

An element with pui-accordion-icon in the summary replaces the drawn chevron. Placement and the rotation on open stay with the library, so any icon set works.
