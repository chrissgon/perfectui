Perfect UI v1 — preview

Phases 2 to 4: tokens, color mode, the style + color contract, and the first shapes — pui-btn, pui-chip and pui-badge.

Color tokens

Every value is a light-dark() pair: v0 tone 600 in light, 500 in dark. The label on a solid fill is always the page background, which is what gives the palette its v0 look. In light mode that leaves pui-solid with theme, success and warn between 3.19:1 and 3.50:1 — above the 3:1 floor for interface elements, below WCAG AA. Text uses a deeper derived tone and stays at or above 4.5:1 everywhere.

Base tokens

Only four exist. Components derive every size from them with calc(), so changing one rescales the library.

Styles × colors

Shape, style and color are independent classes. The cells below are all the same element with two classes swapped. Hover them: the hover tone is derived with color-mix(), never hardcoded.

Shapes

Size is expressed by choosing a component, never by a modifier class: pui-btn > pui-chip > pui-badge. All three read the same four base tokens, so they rescale together.

Containers

A card is a surface: it uses the page tokens directly, so it works with no extra classes, and a style class still overrides it. Timeline icons are colorable elements — give them a style and a color. Forms

The label is a real <span> and the message a real <small> tied to the control with aria-describedby, so screen readers announce them and the text can be selected and translated. The error state is aria-invalid on the control — no class — which repoints --pui-edge and turns the message red through :has().

Overlays and disclosure

These four are native HTML behavior, not JavaScript: <details name> for the exclusive accordion, popover for the dropdown, interestfor plus popover="hint" for the tooltip, and <dialog closedby> plus commandfor for the modal. Click them: nothing here is wired up with script.

Does it need JavaScript?

Only to emulate what a browser is missing.

Is Tailwind required?

No, it is an optional complement.

How big is it?

Smaller than the 0.23.0 build it replaces.

States

Disabled, invalid and focus live in the last layer. Press Tab to see the focus ring, which takes the element's own color.

Overriding

All library CSS lives in @layer pui.*, so any unlayered rule of yours wins with no !important. The button on the right is the same markup with a plain .brand class setting --pui-color.
